Vehere NDR (Network Detection and Response) is a platform for detecting, investigating, and responding to threats using network telemetry — full packet capture, metadata, signatures, IOC/IOA matching, and behavioral and ML-based analytics.

The platform is built around a single continuous workflow rather than a set of disconnected modules:

**Capture → Detect → Enrich → Investigate → Hunt → Case → Respond**

## Who this guide is for

This public product guide is written for security analysts, prospective customers, partners, and technical evaluators who need to understand *what* Vehere NDR does and *how* it works — without requiring access to the restricted internal User Manual, which covers step-by-step configuration and administration.

:::tip Looking for configuration steps?
Detailed installation, configuration, and administration procedures live in the internal User Manual. This guide focuses on architecture, capabilities, and workflows.
:::
